Arivazhagan M. - Portfolio (HTML / CSS / JS)

Files
  index.html  - page structure
  style.css   - styles (responsive: 320px phones to 1920px+ desktops)
  script.js   - interactions + CONFIG block at the top

How to run
  Double-click index.html (needs internet once for Google Fonts), or host the folder on Netlify / Vercel / GitHub Pages.

Edit your details
  Open script.js and fill the CONFIG block at the top:
  email, github, linkedin, resume (e.g. "resume.pdf" - put the file next to index.html),
  formEndpoint (e.g. a Formspree URL so the contact form sends real messages),
  and each project's repo / demo links.
  Buttons stay disabled until a link is provided.
